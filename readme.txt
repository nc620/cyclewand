This repository contains code for analysing cycle lanes in London

There are 3 analysis files
1. tflcid.ipynb analyses the TFL Cycling Infrastructure Database
    - the CID is included as the cycle_lane_track.json
2. osm_analysis.ipynb analyses the Open Street Map database using the Overpass API
3. osngd_analysis.ipynb is a skeleton code for the Ordnance Survey National Geographic Database

Also included is:
- "Cycle route - sutiable only.geojson" is the sutiable routes identified from the Strategic Network
- CycleRoutes.json is the Strategic Network
- London_GLA_Boundary.geojson is the file for the borough boundaries
